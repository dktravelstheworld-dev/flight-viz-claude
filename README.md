# SFO flight viz

A small, dependency-free web app that shows flights departing San Francisco
International (SFO) as a table: one row per destination, one column per day
of the week, with a total row and column.

- Toggle between **total flights** and **average per day** (the header shows
  how many calendar days of each weekday are in the data).
- Click a column header to sort; type in the box to filter destinations.

## Run it

Requires Node 18+.

```sh
npm start          # serves the app at http://localhost:8000
```

## Data

The app reads `data/flights.csv`:

```csv
date,time,flight,destination
2026-09-07,14:50,UAL2661,LAX
```

`date` and `time` are local SFO time. **The committed file is synthetic sample
data** (generated by `npm run sample`) so the app works out of the box.

To load real departures from the [OpenSky Network](https://opensky-network.org/)
API:

```sh
npm run fetch          # last 7 days
npm run fetch -- 14    # last 14 days
```

Anonymous requests are rate-limited; set `OPENSKY_CLIENT_ID` and
`OPENSKY_CLIENT_SECRET` (an API client from your OpenSky account) for more.
OpenSky reports destinations as ICAO codes (e.g. `KLAX`) and only when it
could infer the arrival airport, so some rows show `UNKNOWN`.
